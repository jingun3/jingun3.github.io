개인정보처리방침

랜덤 히어로 디펜스(Android 앱 1.0.0) · HeartBridge inc · 시행일 2026-10-08

요약: 이 앱은 개인정보를 모으지 않고, 어디로도 보내지 않습니다. 게임 진행은 모두 이 휴대폰 안에만 저장되며, 회원가입・로그인・광고・분석 도구・결제가 없습니다.

1. 모으는 정보

없습니다. 랜덤 히어로 디펜스(이하 "게임")는 이름, 이메일, 전화번호, 위치, 연락처, 사진, 기기 식별자, 광고 ID 등 어떤 개인정보도 모으거나 게임 서버・다른 회사로 보내지 않습니다. 게임은 인터넷 없이도 처음부터 끝까지 할 수 있습니다.

2. 이 휴대폰에만 저장되는 것

  • 게임 진행: 레벨・경험치・골드・보석・히어로・유물・출석・미션・우편함・도감
  • 설정: 소리・알림・그래픽, 본 안내 말풍선
  • 게임 안 닉네임과 무작위로 만든 게스트 번호(UID) — 순위 탭에 이 휴대폰 기록을 보여 주는 데만 씁니다
  • 이 휴대폰에서 한 판의 기록(코스・라운드・점수)

이 정보는 앱의 저장 공간에만 있고 앱 밖으로 나가지 않습니다. 운영자도 이 정보를 볼 수 없습니다.

설정 → 계정 연동의 기기 백업 코드는 이용자가 직접 복사해 다른 휴대폰에 붙여 넣는 글자이며, 게임이 어디로 보내지 않습니다. 백업 코드에는 진행 정보가 들어 있으니 다른 사람에게 알려 주지 마세요.

3. 다른 곳에 주거나 맡기는 것

모으는 정보가 없으므로 다른 회사나 사람에게 주거나 처리를 맡기는 일도 없습니다. 광고, 분석(통계) 도구, 오류 수집 도구를 쓰지 않습니다. 실제 돈으로 사는 상품(인앱 결제)도 없습니다.

4. 데이터 지우기

  • 게임 안에서: 설정 → 계정 연동 → 🗑 계정 삭제 → 확인 두 번. 이 휴대폰의 진행・설정・기록을 모두 지웁니다.
  • 휴대폰에서: 앱을 삭제하거나 설정 → 애플리케이션 → 랜덤 히어로 디펜스 → 저장공간 → 데이터 삭제.

서버에 저장된 정보가 없으므로 따로 삭제를 요청할 것은 없습니다. 궁금한 점은 아래 연락처로 문의해 주세요.

5. 앱 권한

앱은 인터넷 권한만 갖고 있습니다(앱을 만드는 도구의 기본 권한). 1.0.0 버전은 이 권한으로 데이터를 주고받지 않습니다. 위치・카메라・마이크・연락처・사진・파일 권한은 요청하지 않습니다.

6. 아동

게임은 어떤 이용자에게서도 개인정보를 모으지 않으며, 만 14세 미만 아동의 정보도 마찬가지입니다.
