선물 코드 관리

조선좀비러시 · 설정 → 「선물 코드 입력」에서 쓰는 코드 목록(codes.json)을 만드는 운영자 도구입니다. 이 페이지는 아무 데도 저장하지 않습니다. 결과 JSON을 GitHub에 커밋해야 게임에 반영됩니다.

보안 방식

목록에는 코드 원문이 아니라 SHA-256 해시만 들어갑니다. 게임은 입력한 코드를 같은 방식으로 해시해 비교하고, 코드마다 기기(저장 데이터)당 한 번만 지급합니다. 서버가 없으므로 「전체 선착순 N명」 같은 총 사용 횟수 제한은 할 수 없습니다. 짧거나 추측하기 쉬운 코드는 피하세요(8자 이상 권장).
